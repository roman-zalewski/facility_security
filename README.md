# Facility Security SQL Project

This project was created for a database systems class to demonstrate a full SQL pipeline

It uses a mysql server and a relational database. The frontend is built in unity, meant to simulate a keycard scanner. It then pushes SQL queries changing the access log. 
Also included in the frontend is a manager dashboard that allows a user to see who is checked in where and add employees or facilities to the database.
